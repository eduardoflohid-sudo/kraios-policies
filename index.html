Kraios Development Alerts

Informational text notifications for the sole owner of the Kraios software-development project.

The service is designed to notify its owner about approved development tasks, GitHub pull requests, automated tests, code reviews, and development interruptions. It does not provide trading signals, execute trades, or approve code merges by text.

Single-recipient program. The owner explicitly enables SMS delivery to their own configured phone number. There is no public sign-up form, mailing list, or marketing campaign. SMS is not activated until the sender registration and configuration are completed.

Messaging details

Message frequency varies with development activity. The default limit is 12 regular notifications per day, with one additional limit notice possible. Message and data rates may apply. To stop messages, reply STOP to the sending number once SMS is enabled. Reply HELP for assistance, or use the project support link below.
