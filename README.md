# LAVQO Bot Alerts policies (public site)

Static public GitHub Pages content, not the private Kraios trading app or SMS notifier. Contains no phone numbers, personal addresses, or credentials.

## Publish using GitHub Pages
In repository Settings > Pages choose **Deploy from a branch**, branch **main**, folder **/(root)**, and Save.

Once GitHub Pages has deployed, verify these pages return publicly accessible content:
- https://eduardoflohid-sudo.github.io/kraios-policies/

## Before submitting to Twilio
- Check that the exact registered Twilio legal Brand name appears on both policies. This draft uses the program name **Kraios Development Alerts**; update if the registered brand is your legal personal name.
- Confirm the public support-issues link is monitored and Twilio accepts it, or supply a monitored support email.
- Verify STOP and HELP handling in the Twilio Messaging Service before enabling actual SMS.
- Provide separate, accurate opt-in evidence (for single-recipient configuration, a redacted screenshot), not the policy pages as proof of a public signup form.
- Do not publish your mobile number, identity documents, credentials, or unredacted settings.
